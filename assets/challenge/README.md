# 챌린지 예시 영상

챌린지 상세 화면의 "이렇게 찍어 주세요" 예시 영상과 첫 장면(포스터).
표 challenges 의 example_video 칸이 이 파일을 가리킨다 (0031).

## 저작권
출처는 Pexels 만 쓴다 (https://www.pexels.com/license/) — 무료, 상업적 이용 가능, 출처 표기 의무 없음.
뉴스·방송·SNS 에 올라온 남의 아이 영상은 쓰지 않는다 (저작권·초상권).
화면에는 "예시 영상 · Pexels" 로 표시한다. 회원 참가작처럼 보이게 쓰지 않는다.

## 고르는 기준 (모든 영상)
- 그 챌린지가 바라는 장면이 처음 12초 안에 분명히 보일 것

# 나눔스퀘어라운드

네이버가 배포한 원본 WOFF2 파일을 수정 없이 포함한다. 외부 폰트 CDN이 느리거나 차단되어도 앱과 같은 출처에서 받을 수 있게 하기 위함이다.

- 배포처: https://hangeul.naver.com/font
- 공식 CSS: https://hangeul.pstatic.net/hangeul_static/css/nanum-square-round.css
- 원본 경로: `https://hangeul.pstatic.net/hangeul_static/webfont/NanumSquareRound/`
- 파일: `NanumSquareRoundR.woff2` (400), `NanumSquareRoundB.woff2` (700), `NanumSquareRoundEB.woff2` (800)
- 내려받은 날: 2026-10-22
- 라이선스: SIL Open Font License 1.1. 같은 폴더의 `OFL.txt` 참조.
- 공식 저작권 안내: https://help.naver.com/service/30016/contents/18088?osType=PC&lang=ko

`rounded-ui.css`에서 `font-display: swap`과 시스템 대체 글꼴을 지정한다. 폰트 파일 자체는 수정·서브세팅하지 않았다.

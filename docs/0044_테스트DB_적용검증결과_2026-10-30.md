## 자동 정리 — 등록과 실행을 구분한 기록

- 함수는 **파일럿 코호트만** `enrolled_at <= statement_timestamp() - interval '89 days'` 조건으로 삭제한다. 일별 활동만 FK cascade로 지워진다. 다른 데이터 표나 다른 cron은 변경하지 않는다.
- 매일 최대 24시간 간격을 고려해 89일에 정리 대상으로 삼는다. 정상 일일 실행 시 최대 하루 일찍 지워질 수 있으며 등록 후 90일 상한을 지킨다. 작업 장애/중단 시 자동 파기를 보장한다고 주장하지 않는다.
- `pg_cron` 설치 및 `cron.timezone=GMT` 확인. 등록 리허설 롤백 뒤 파일럿 작업 0건 확인.
- 검증용 작업 **jobid 5**: 같은 전용 이름/명령을 1분 간격으로 실행. 실제 `succeeded`, 2026-10-30 **08:54:00.107636~08:54:00.111761 KST**, 반환 메시지 `1 row` 확인. 이 메시지는 SELECT 결과 1행이며 삭제 1건을 뜻하지 않는다. 당시 파일럿 두 표가 비어 있어 삭제할 자료는 없었다. 정리 대상/cascade와 비대상 보존은 위 원격 transaction fixture로 별도 검증했다.

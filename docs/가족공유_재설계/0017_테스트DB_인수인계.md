## 바뀐 처리

`family_members`의 삭제 트리거에서 종료 이력과 `updated_by` 연결 제거를 함께 처리한다.
나가기·방장의 구성원 제거·계정 탈퇴 경로 모두에 적용된다. 한 단계라도 실패하면 트랜잭션 전체가 취소된다.
강제 제거도 있으므로 종료 이력의 scope는 `family_membership_end`이며 자발적 철회라고 단정하지 않는다.
회원 탈퇴 시에는 기존 FK cascade대로 계정의 동의 이력도 삭제된다.

`leave_family()`는 `{ok:true, consent_revoked:true, privacy_version:17}`을 반환한다.
응답 유실 후 다시 호출해도 최근 종료 이력이 이미 false이면 같은 종료를 중복 생성하지 않는다.
공유 중인 계정의 연결은 유지하며, 과거에 나간 계정의 잔존 연결만 보정한다.
내용·시각·삭제 표시는 보존하고, 마지막 구성원이 나가면 기존 방식대로 가족과 기록을 삭제한다.

## 되돌리기 주의

실패한 트랜잭션은 전부 rollback된다. commit 후에는 공유 기능을 점검한 뒤 트리거와 함수 정의를
0016으로 되돌릴 수 있으나, 보안 보완을 제거하므로 기본 복구 방법으로 권장하지 않는다.
종료 이력은 지우지 않는다. 해제한 계정 연결은 자동으로 복원할 수 없다.
이번 보정은 전체 기록 삭제가 아니라 비구성원의 `updated_by` 연결만 제거한다.

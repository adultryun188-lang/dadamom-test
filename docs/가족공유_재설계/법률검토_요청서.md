# 다다맘 가족 공유 기능 — 개인정보 법률 검토 요청서

작성: 2026-10-16. 검토하실 분께 그대로 전달하는 용도입니다.
함께 볼 문서: `개인정보처리방침_수정안_2026-10-16.md` (방침에 추가할 문안 전체)

## 1. 서비스와 기능 요약

- **다다맘**: 임신·육아 기록과 부모 커뮤니티 웹앱 (운영: 다다란, 개인사업자). 회원은 만 14세 이상 보호자.
- **지금까지**: 수유·수면 기록, 키·몸무게, 예방접종 체크는 **이용자 기기에만** 저장. 서버로 보내지 않음.
- **추가하려는 기능 — 가족 공유(선택)**
  - 이용자가 **별도 동의**하고 켜면, 위 기록이 서버(Supabase, 저장 지역 서울 `ap-northeast-2`, 제공사 Supabase Inc. 미국)에 저장됨.
  - 초대 코드(10자리, 24시간 유효)로 **최대 4명**이 같은 아이의 기록을 함께 보고 남김. 서비스가 실제 가족관계를 확인하지는 않음.
  - 운영자 화면에는 가족 기록을 보는 기능이 없음. DB 관리 권한은 별도.
  - 나가거나 탈퇴하면: 그 사람의 참여 정보 삭제, 기록의 "마지막 수정 계정" 연결 제거, **기록 내용은 남은 가족에게 공동 기록으로 남음**.
    마지막 구성원이 나가면 서버의 가족 기록 전체 삭제. 각 기기에 내려받은 사본은 남음.
  - 동의·종료 이력은 계정에 연결해 남기고, 회원 탈퇴 시 계정과 함께 삭제.

## 2. 여쭙고 싶은 것

1. **공동 기록 보관**: 나간 사람이 남긴 기록을 (작성자 연결만 지우고) 남은 가족에게 계속 보관하는 것이,
   동의 철회·삭제 요구(개인정보 보호법 제36·37조)와 충돌하지 않는지. 충돌한다면 어떤 고지·절차가 필요한지.
2. **삭제 요청 처리**: 삭제 요청은 문의 이메일로 받기로 했습니다. 다만 나간 뒤에는 어느 기록이 그 사람 것인지 서버에서
   가려낼 수 없습니다(마지막 수정 계정만 남기고, 나가면 그 연결도 지움). "가족 공유에서 나가기 전에 요청"으로 한정하는
   안내가 가능한지, 아니면 처음 작성자를 따로 기록해야 하는지.
3. **아동 정보**: 아이의 성장·접종 기록은 보호자가 입력합니다. 건강 관련 정보(민감정보 해당 여부 포함)로 보아 별도 동의·고지가
   더 필요한지. 현재는 "[필수] 가족 공유를 위해 육아 기록을 서버에 저장하는 데 동의" 체크 하나를 받습니다.
4. **제3자 제공 여부**: 이용자가 직접 초대한 가족 구성원에게 기록이 보이는 것을 처리방침에서 어떻게 분류해 적어야 하는지
   (제3자 제공 / 이용자 간 공유 / 기타). 현재 초안은 법적 분류를 단정하지 않고 실제 흐름만 설명합니다.
5. **처리위탁·국외이전**: 저장 지역은 서울이지만 제공사는 미국 법인(Supabase Inc.)입니다. 위탁 고지만으로 충분한지,
   국외이전 고지가 필요한지.
6. **동의 이력 보관 기간**: 동의·종료 이력을 회원 탈퇴 때까지 보관하는 것이 적절한지.
7. **시행 절차**: 공지 후 7일 뒤 시행하려 합니다. 이 변경이 "중요한 변경"으로 30일 사전 공지가 필요한 경우인지.

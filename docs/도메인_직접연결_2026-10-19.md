## 승인 및 범위

- 사용자가 GitHub Pages 설정 확인 및 dadamom.co.kr 운영 연결을 요청했고, 기존 이동 방식과 직접 연결의 차이·브라우저 저장 기록 이전 위험을 안내한 뒤 **2번 직접 연결**을 명시적으로 선택했다.
- 운영 DB 직접 조회·수정, SQL, Auth 설정 변경, 회원 로그인·가입·게시물 조작은 하지 않았다. 새 도메인에서 비로그인 공개 화면 표시만 확인했다.
- 작업 기준 폴더는 최신 dadamom-test, 브랜치는 staging이다. 기존 미커밋 변경을 보존했다.

## 발견 및 변경

- 기존 dadamom-link 저장소의 Custom domain이 dadamom.co.kr을 선점하고 있었다. 이 저장소는 기존 GitHub 운영 주소로 이동시키는 중계 페이지였다.
- 사용자의 직접 연결 선택 후 dadamom-link > Settings > Pages에서 Custom domain을 Remove했다. 저장소와 중계 페이지 본문은 삭제하지 않았다.
- dadamom-app > Settings > Pages에서 Custom domain = dadamom.co.kr을 저장했다.
- 배포 소스 Deploy from a branch / main / root는 그대로 유지했다. 기능 코드를 편집하거나 다른 변경 묶음을 운영으로 이관하지 않았다. GitHub가 관리하는 도메인용 CNAME 변경은 이 설정 작업에 포함된다.
- DNS check successful, Enforce HTTPS 체크됨을 확인했다. 가비아 DNS는 이번 작업에서 변경하지 않았다.

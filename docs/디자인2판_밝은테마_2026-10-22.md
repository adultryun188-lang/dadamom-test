# 디자인 2판 이어받기 — 밝고 따뜻한 테마

작업일: 2026-10-22 / 작업 환경: `dadamom-test`, `staging`

## 요청과 범위

- Claude가 남긴 `community.html` 미커밋 밝은 테마 수정(25줄 추가·18줄 삭제)을 보존하고 이어서 보완했다.
- 큰 어두운 배경은 사용하지 않고 크림·살구·버터 옐로·연한 민트 계열을 사용한다. 본문 글자는 가독성을 위해 진한 웜 브라운을 유지한다.
- `index.html`, 인증 설정, DB 스키마·회원·게시글 데이터는 변경하지 않았다. 운영 앱과 운영 DB는 작업 대상이 아니다.
- 기존 `docs/디자인2판/` 캡처와 `docs/로고/앱첫화면_로고.png`는 건드리지 않았다.

## 보완한 부분

1. 홈·챌린지 배너와 앱 안내 카드를 밝은 표면으로 통일했다.
2. 검색·가입·로그인·글쓰기·참여 버튼, 선택한 필터·페이지·응원 상태, 알림 토스트·상품 배지를 밝은 바탕과 대비가 높은 글자로 변경했다. 소셜 제공자 공식 버튼 색상은 유지한다.
3. 주제별 카드에는 옅은 하늘·노랑·라벤더·민트를 사용하고, 단계 안내에는 따뜻한 파스텔 표면을 적용했다.
4. 홈 참가작은 실제 공개된 작품만 표시한다. 4칸을 채우던 빈 타일은 제거하고 참여 안내 카드 1개로 대체했다. 사진 경로가 없는 참가작은 임의 사진 대신 이름을 보여준다.
5. 모바일 참여 버튼을 세로 배치하고, 인기글 제목은 2줄까지 표시한다. 글쓰기·선택 버튼의 최소 높이는 44px이다.
6. 키보드 본문 바로가기와 명확한 초점 표시를 추가했다. 본문 이동은 SPA 해시를 바꾸지 않는다.
7. `SHOW_TEST_BADGE`가 켜진 환경에서만 로고 옆에 테스트 표시가 나온다.

- 운영 이관 시 테스트 배지·환경 설정을 옮기지 않는다.
- 사진이 없는 참가작의 실제 사진과 비어 있는 브랜드 상품 이미지는 임의 실사로 채우지 않았다. 실제 콘텐츠 등록은 별도 작업이다.
- 이번 작업으로 새 인증 기능이나 결제·주문 기능이 구현된 것은 아니다.

## 3차 보완 — 둥근 글꼴·부드러운 클릭 UI (2026-10-22)

사용자가 홈 챌린지 영역을 캡처해 "글씨체는 더 둥글게, 클릭 UI는 덜 딱딱하게" 요청했다.

- 네이버 공식 원본 나눔스퀘어라운드 400/700/800 WOFF2를 `assets/fonts/`에 포함했다(합계 705,884바이트). 출처·원본 해시·SIL OFL 1.1 라이선스를 같은 폴더에 남겼다. 외부 폰트 CDN 요청은 제거했다.
- `rounded-ui.css`를 웹·앱·정적 안내 화면에서 공용으로 사용한다. `font-display:swap`으로 다운로드 중에는 시스템 글꼴을 쓴다.
- 참여/로그인/글쓰기 버튼, 필터, 탭, 검색창은 여유 있는 알약형으로 변경했다. 선택 메뉴는 밑줄형에서 둥근 표면으로 바꿨다. 정적인 정보 칩에는 버튼과 같은 그림자를 넣지 않는다.
- 챌린지 모서리, 참가작 카드, 상품/게시글/주제 카드, 입력창도 둥글게 정돈했다. 글자 대비와 44~48px 이상의 주요 터치 영역은 유지한다.
- 마우스가 있는 기기에서만 가벼운 떠오름/그림자를 사용하고, 누르면 약간 들어가는 반응을 준다. `prefers-reduced-motion`에서는 이동/애니메이션을 끈다. 소셜 제공자 색상·아이콘은 유지한다.
- 링크에 `?v=20261022-1`을 넣어 서비스워커의 예전 CSS 캐시와 분리했다. **다음에 공용 CSS를 수정하면 HTML의 버전도 갱신한다.** 폰트는 수정하지 않은 원본이므로 계속 캐시해도 된다.
- 404의 중첩 경로에서도 공용 CSS 주소를 앱 루트에 맞춰 복구한다. 계정 삭제 절차나 정책 내용은 바꾸지 않는다.

## 4차 보완 — 굵은 글자·브랜드관 재배치·디자인 참고 (2026-10-22)

사용자가 "글씨가 얇고 브랜드관 배치가 엉망"이라고 피드백하며 Baby On Board와 Yumi를 참고 자료로 제공했다. 두 사이트를 실제 브라우저에서 열어 확인했다.

- 참고: https://www.behance.net/gallery/235407665/Baby-On-Board / https://helloyumi.com/?ref=land-book.com
- Baby On Board의 큰 색면·굵은 제목·둥근 그래픽, Yumi의 명확한 제목/설명 위계·정돈된 상품 카드 구성을 참고했다. 상대 사이트의 로고·눈 모양 심볼·사진·상품 이미지·원본 자산은 복제하지 않았다.
- 다다맘의 둥근 글꼴과 크림/살구를 유지하고 버터 옐로·옅은 민트를 더했다. 큰 어두운 배경은 쓰지 않는다. 기존 다다맘 아이콘과 CSS 도형으로 새 소개 영역을 구성했다.

- 브랜드관은 사이드 피드를 빼고 가로 공간을 사용한다. **소개 영역 → 기획전 배너 → 한 번만 보이는 브랜드 목록 → 전체/브랜드/진행 중 특가 필터와 상품 목록** 순서다. 다른 메뉴에서는 기존 사이드가 복구된다.
- 잘린 수평 배너와 중복된 신규/추천/전체 브랜드 줄을 제거하고, 브랜드의 NEW/추천 표시를 단일 카드에 모았다. 상품 카드 폭·사진 비율·정보 위치를 통일했다. 모바일은 상품 2열, 브랜드 목록 1열이다.

- 사진이 없는 상품은 임의 실사나 곰 이모지 대신 "상품 사진 준비 중" 자리표시자를 쓴다. 실제 사진 등록은 별도 콘텐츠 작업이다.

- 실제 배포 화면 점검 중 할인 상품만 특가 배지 때문에 제목이 내려가고 정가/할인가의 기준선도 다른 것을 발견했다. 특가 배지는 이미지 위로 옮기고 가격 묶음의 높이를 통일해 같은 줄의 상품명·가격·구매 버튼을 맞췄다.

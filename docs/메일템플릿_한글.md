# 가입·로그인 메일 한글화 (Supabase → Authentication → Emails → Templates)

앱이 보내는 메일은 두 가지뿐이다 (`index.html`: `signUp` → **Confirm sign up**, `signInWithOtp` → **Magic link**).
비밀번호 재설정은 앱에 없어서 그대로 둔다.
`{{ .ConfirmationURL }}` 은 바꾸지 않는다 — 이게 인증 링크다.

넣는 곳: 운영(`hjqchbpxwviengdzvado`)·테스트(`srxdtddrtnhtlbbviyvs`) 각각 대시보드에서 사장님이 붙여넣고 **Save**.
(Supabase 인증 설정은 코드 세션이 바꾸지 않는다 — CLAUDE.md 6장)

# 초음파 영상 성별 예측 — 방안 (2026-10-28, Claude + 조사 에이전트 2)

## 사장님이 정한 조건
1. 카페 판정과 **똑같이** 예측한다 (카페 적중률 80% 이상).
2. 데이터 한 세트 = **영상 + 카페가 댓글로 준 성별**.
3. **사용량을 아주 적게** 쓰면서 영상을 짧은 시간에 한꺼번에 확인하는 처리기를 만든다. 한 번 만들면 계속 쓴다.
4. 카페는 성별만 답하고 근거를 안 쓴다 → **왜 그 성별인지 Claude 가 알아내는 것이 핵심.**

## 전체 구조 (네 칸)

### A. 영상 처리기 — 이 컴퓨터에서 무료 프로그램으로, Claude 사용량 0
| 순서 | 하는 일 | 근거 |
|---|---|---|
| 1 | 영상을 한 번만 읽어 1초에 2장씩 작은 사진으로 | 측정: 6분 영상 약 11초 (그래픽카드 AMD RX 6600 가속) |
| 2 | 초음파 부채꼴만 남기고 화면 글자·눈금은 지움 (이름·병원 정보도 같이 사라짐) | 글자로 답을 외우는 꼼수 차단 |
| 3 | 측정 장면에 뜨는 주수 글자(예: 12w1d) 읽어 따로 저장 | 판정자는 주수를 먼저 볼 가능성이 큼 |
| 4 | 화면이 멈춘 장면(의사가 재는 장면) 표시 | 핵심 장면 후보 |
| 5 | 사진마다 특징 숫자 뽑기 (무료 그림 모델 23MB) | 사진 1장 15~30천분의 1초 (추정) |

### B. 따라 하기 학습 — Claude 사용량 0
- 영상마다 "아들 쪽/딸 쪽 점수"를 배우게 하고 **카페 답과 몇 % 같게 맞히는지** 잰다.
- 같은 산모 영상이 연습용과 시험용에 섞이지 않게 나눈다 (점수가 부풀지 않게).
- 성별 단서가 보이는 장면은 몇 초뿐이라, 전체 평균이 아니라 **점수가 높은 장면들 위주**로 판단하게 한다.
- 함정 검사: 지운 글자 부분만으로 맞혀지는지, 병원 기계 종류로 맞히는지 확인한다.
- 좌우 뒤집은 사진으로 늘리지 않는다 (램지법은 태반의 좌우가 단서).
- 목표: 카페와 일치 90% 이상 → 실제 적중률도 카페 수준(80% 안팎)이 된다.

### C. 이유 찾기 — Claude 가 하는 핵심 일, 사용량 아주 조금
1. 처리기가 영상마다 **"아들 판정에 가장 크게 작용한 장면"과 "딸 판정에 크게 작용한 장면"**을 골라 9장씩 한 그림으로 모은다.
2. Claude 는 영상 수천 개 대신 **모음 그림 수십 장만** 본다.
3. 알려진 방법과 대조한다 (조사 결과):

| 방법 | 주수 | 장면 | 기준 | 알려진 정확도 |
|---|---|---|---|---|
| 각도법 | 11~14주 (12주 후반부터 믿을 만) | 옆모습(등뼈·엉덩이가 함께 보이는 면) | 결절이 수평선에서 30도 넘게 들리면 아들, 10도 미만·아래면 딸, 사이는 판단 불가 | 11주 70%, 12주 99%, 13주 100% (1999년 172명 연구), 주수 섞이면 전체 약 80% |
| 삼각점법 | 14~16주 이후 | 다리 사이 | 삼각점이 보이면 아들, 세 줄이면 딸 | 13주 이후 99~100% |
| 램지법 | 6~8주 | 아기집 전체 | 태반 오른쪽 아들, 왼쪽 딸 (좌우 논란) | 근거 약함 (277명 연구에서 관련 없음) |
| 두개골법 | 12주 전후 | 옆얼굴 | 각진 턱·눈썹뼈면 아들 | 논문 없음 |

4. **주수별로 나눠 본다.** 12~13주 영상에서 옆모습 결절 장면이 뽑히면 각도법, 15주 이후에서 다리 사이 장면이 뽑히면 삼각점법을 쓰는 것으로 본다.
5. **가설 검사:** 각도법으로 보이면 그 장면에서 각도를 재는 기능을 붙여 "각도 숫자 vs 카페 답"을 비교 → 30도 기준이 맞는지, 카페만의 기준값이 있는지 확인한다.
6. 결과물: **"카페 판정 방식 해설서"** — 주수별로 어느 장면에서 무엇을 보고 기준값이 얼마인지, 예외는 무엇인지.

에이전트는 무거운 처리에는 쓰지 않고(사용량), C 단계의 판단 일에만 쓴다: 모음 그림을 나눠 보고 각자 소견 → Claude 가 종합, 검증 담당이 꼼수·부풀림 점검.

### D. 다다맘 기능 (나중)
- 휴대폰 안에서 영상을 처리하고 서버로 보내지 않는다 (모델 4~23MB, 6분 영상 30초~1분 30초 추정).
- 예측과 함께 **근거 장면**을 보여 준다 ("이 장면의 각도로 판단했어요").
- 걸리는 것: 지금 사이트(깃허브 페이지)는 여러 계산을 동시에 돌리는 설정을 못 해 느릴 수 있음 → 앱의 서비스워커를 손보거나 다른 방식.
- 경쟁: 베이비빌리가 초음파 **사진** 성별 예측을 이미 무료로 함(근거 비공개). 차별점 = 영상 + 근거 장면 + 카페 수준 적중률.
- "재미·참고용" 안내.

## 시간·공간 (영상 1,000개 × 평균 6분 기준)
- 처리 전체: **하룻밤(6~10시간)**, 학습은 몇 분.
- 뽑은 사진 약 4.5GB, 특징 숫자 0.5GB, 프로그램 0.5GB.
- **원본 영상 90~360GB → C 드라이브 여유(69GB) 부족.** 외장 하드에 두거나 나눠서 받기 → 처리 → 원본 지우기.
- 설치할 무료 프로그램: 그림 계산·학습·글자 읽기용 몇 개 (지금은 하나도 없음).

## 단계
| 단계 | 영상 수 | 하는 일 |
|---|---|---|
| 1 시험 | 30개 (아들 15·딸 15, 주수 섞어서) | 처리기 1판, 모음 그림, Claude 첫 가설 |
| 2 검증 | 300~500개 | 학습, 카페와 일치율, 가설 검사(각도 재기) |
| 3 전체 | 전부 | 하룻밤 처리, 최종 일치율, 해설서 |
| 4 기능 | — | 다다맘 테스트 사이트에 먼저 |

## 위험
- 정답이 카페의 예측이라, 우리 모델은 카페를 따라 할 뿐이다. 실제 적중률은 실제 결과(태어난 성별)가 있는 영상으로만 잴 수 있다.
- "80%"는 자료로 확인된 숫자가 아니다. 다만 각도법의 주수 섞인 전체 정확도(약 80%)와는 맞는다.
- 영상이 짧게만 단서를 보여 주면 신호가 약하다 → 멈춘 장면·상위 장면 위주로.

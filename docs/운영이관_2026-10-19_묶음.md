## 만드는 법 (다시 할 때)

```bash
git -C <운영 저장소> show origin/main:index.html > base.html      # LF
git show HEAD:index.html > test.html
git diff --no-index -U0 base.html test.html > full.diff
node scripts/prod/hunks_list.mjs full.diff                     # 훅 목록·분류 (FAM/MIXF/ENV/MIXE/OK)
node scripts/prod/hunks_select.mjs full.diff prod.patch <번호들> --show
node scripts/prod/apply_u0.mjs base.html prod.patch cand.html   # 지울 줄이 한 글자라도 다르면 멈춤
```

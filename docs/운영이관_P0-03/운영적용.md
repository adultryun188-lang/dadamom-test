### 2) 이어서 이 세 줄을 Run

#### ⚠️ 2번이 왜 필요한가 — 0005 만으로는 하나가 안 지워집니다

`0005` 의 166행은 이렇습니다.

```sql
drop function if exists public.increment_comments(uuid, int);
```

그런데 **운영의 실제 시그니처는 `increment_comments(p_id uuid)` — 인자가 하나**입니다
(2026-10-14 `pg_proc` 조회로 확인). `(uuid, int)` 로는 안 걸리고 **함수가 살아남습니다.**
보안 권고가 anon 실행 가능으로 잡은 셋 중 하나입니다.

`increment_votes`·`increment_likes` 는 `(p_id uuid, delta integer)` 라 원본 그대로 걸립니다.

## 사소한 지적 (배포 막는 건 아님)

`clearAuthDraft()` 는 로그인 성공과 모달 닫기에서만 불립니다. 첫 화면에서
비밀번호를 치다가 "둘러보기" 로 나가면 `authDraft.password` 가 메모리에 남습니다.
DOM 에 있을 때와 같은 수명이라 새로 생긴 노출은 아니지만, 화면을 떠날 때도
비우는 편이 깔끔합니다.

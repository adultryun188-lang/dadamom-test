## ⚠️ 남은 것 하나 — 예시 나들이가 DB 에 있습니다

배포본에 `가을 단풍 나들이 축제` 는 **없습니다**(코드에서 제거됨). 그런데 브라우저
DOM 에는 그 문자열이 **남아 있습니다.** 앱이 `fetchOutings()` 로 DB 에서 받아오므로,
**운영 `public.outings` 표에 예시 행이 들어 있는 것**으로 보입니다.

코드에서 `OUTINGS = []` 로 바꿔도 DB 행이 있으면 화면에 계속 나옵니다.
확인하려 했으나 Supabase 커넥터 인증이 끊겨 조회하지 못했습니다.

→ 확인 SQL:
```sql
select id, category, region, title, place from public.outings order by title;
```
예시 행(가을 단풍 나들이 축제, 인천 어린이 과학축제 등)이 있으면 지워야 합니다.

## 고친 것

### ① `<meta charset="utf-8">`
없으면 GitHub Pages 밖에서 한글이 전부 깨집니다 (CLAUDE.md 지뢰 목록).
계속 "별도 승인" 으로 밀려 있던 항목입니다.

운영본에는 **`<head>` 태그가 아예 없어서** `<html lang="ko">` 바로 다음에
넣었습니다. 1024바이트 안에 들어가는 것을 실측 확인했습니다
(`t.slice(0,1024).includes('<meta charset="utf-8">')` → `true`).

### ① 앱 아이콘
선언이 아예 없어 브라우저가 `/favicon.ico` 를 찾다 **404** 를 냈습니다.
테스트 앱의 아이콘 3개(192 · 512 · apple-touch)를 가져와 선언을 넣었습니다.
매니페스트·서비스워커는 테스트 전용이라 넣지 않았습니다.

- 배포 후 `icons/icon-192.png` → **200**
- 깨끗한 새 탭에서 운영 앱 로드 → **콘솔 로그 0건** (404 사라짐)

### ③ 체험단 신청 id 실패 시 접수 차단
`newUuid()` 는 `window.crypto` 가 없으면 `null` 입니다(1363~1373줄).
그때 `handleApplySubmit` 은 신청 행만 넣고 PII insert 를 `if(appId)` 로
건너뛰었습니다. 사용자에게는 "접수됐어요" 로 보이는데 **연락처·주소가
아무 데도 안 남아 당첨돼도 보낼 수가 없습니다.**

이제 `appId` 를 못 만들면 접수하지 않고 최신 브라우저로 다시 시도하라고
알립니다. `payload` 에 `id` 를 항상 넣습니다.

### ④ 비밀번호 메모리 잔류
`clearAuthDraft()` 가 로그인 성공과 모달 닫기에서만 불려서, 첫 화면에서
비밀번호를 치다가 "둘러보기" 로 나가면 메모리에 남았습니다. 그 경로에서도 비웁니다.

## 확인 — 테스트 앱에서 눌러본 것 (CLAUDE.md 8절)

③ 은 `window.crypto` 가 없어야 발동해 클릭으로 재현할 수 없고, ④ 는
메모리 동작이라 화면에 안 보입니다. 그래서 **관찰 가능한 경로**로 확인했습니다.

| 테스트 | 결과 |
|---|---|
| 첫 화면에 이메일·비밀번호 입력 → "둘러보기" → 커뮤니티 모달 열기 | 모달 입력칸 **빈 상태** ✅ |
| 그 상태에서 모달 안 탭 전환 (`refreshAuthForms` → `restoreAuthDraft` 발동) | 여전히 **빈 상태** ✅ |
| 같은 화면 안에서 탭 전환 (핫픽스가 하던 일) | 이메일·비밀번호(12자) **보존** ✅ |

즉 **"같은 화면에서는 보존, 화면을 떠나면 폐기"** 가 둘 다 성립합니다.
핫픽스를 깨지 않았습니다.

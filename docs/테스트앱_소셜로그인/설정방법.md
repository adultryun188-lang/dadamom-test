> 제공자 등록이 안 돼 있어서 버튼을 누르면 `provider is not enabled` 라는 날것의
> 에러 화면이 떠서 일부러 꺼 둔 상태였습니다.
>
> **코드 쪽은 제가 켭니다. 아래 대시보드 3곳은 사장님만 하실 수 있습니다**
> (비밀키를 다뤄야 해서 제가 손대지 않습니다).
>
> ⚠️ **client secret 을 저한테 보내지 마세요.** 대화에 붙여넣지 마시고 대시보드에만
> 입력하세요. 제가 알 필요가 없는 값입니다.

## 1. 구글 — 리디렉션 주소 추가

1. https://console.cloud.google.com/apis/credentials 접속
2. 운영 다다맘에 쓰는 **OAuth 2.0 클라이언트 ID** 클릭 (웹 애플리케이션)
3. **승인된 리디렉션 URI** → `+ URI 추가`
4. 붙여넣기: `https://srxdtddrtnhtlbbviyvs.supabase.co/auth/v1/callback`
5. **저장**
6. 그 화면의 **클라이언트 ID** 와 **클라이언트 보안 비밀번호**를 복사해 둡니다 (3번에서 씁니다)

> 기존 운영용 URI 는 지우지 마세요. **추가**만 하는 겁니다.

---

## 2. 카카오 — Redirect URI 추가

1. https://developers.kakao.com/console/app 접속 → 다다맘 앱 선택
2. 왼쪽 **카카오 로그인** → **활성화 설정** ON 인지 확인
3. 같은 화면의 **Redirect URI** → `Redirect URI 등록`
4. 붙여넣기: `https://srxdtddrtnhtlbbviyvs.supabase.co/auth/v1/callback` → 저장
5. 왼쪽 **보안** → **Client Secret** 이 "사용함" 인지 확인 (아니면 코드 발급 후 사용함으로)
   그 **Client Secret 코드**를 복사해 둡니다
6. 왼쪽 **앱 키** → **REST API 키**를 복사해 둡니다
7. 왼쪽 **카카오 로그인 → 동의항목** → `profile_nickname`, `profile_image` 가 켜져 있는지 확인
   (앱이 이 두 가지를 요청합니다)

---

## 3. Supabase 테스트 프로젝트에 등록

1. Supabase → **dadamom-test** (주소창에 `srxdtddrtnhtlbbviyvs` 확인)
2. 왼쪽 **Authentication** → **Sign In / Providers**

**Google**
- 토글 ON
- Client ID: 1번에서 복사한 클라이언트 ID
- Client Secret: 1번에서 복사한 보안 비밀번호
- Save

**Kakao**
- 토글 ON
- Client ID: 2번의 **REST API 키**
- Client Secret: 2번의 **Client Secret 코드**
- Save

3. 왼쪽 **Authentication** → **URL Configuration**
   - **Site URL**: `https://adultryun188-lang.github.io/dadamom-test/`
   - **Redirect URLs** 에 추가: `https://adultryun188-lang.github.io/dadamom-test/**`

> 마지막 `**` 두 개 꼭 넣어주세요. 앱이 `#home` 같은 해시를 붙여 돌아오기 때문에
> 정확히 일치하는 주소만 허용하면 로그인 후 튕깁니다.

제가 테스트 앱의 `SOCIAL_LOGIN` 을 켜서 배포하고, 카카오·구글 버튼이 뜨는지
직접 눌러서 확인하겠습니다. (로그인 자체는 사장님이 해주셔야 합니다 —
저는 계정 자격증명을 입력하지 않습니다.)

## 안 되면 보는 곳

| 증상 | 원인 |
|---|---|
| `provider is not enabled` | 3번의 토글이 꺼져 있음 |
| `redirect_uri_mismatch` (구글) | 1번 주소 오타 — 끝에 `/auth/v1/callback` 까지 정확히 |
| `KOE006` (카카오) | 2번 Redirect URI 미등록 |
| 로그인은 되는데 앱으로 안 돌아옴 | 3번 URL Configuration 의 `**` 누락 |
| 카카오 닉네임이 안 들어옴 | 2-7번 동의항목 꺼짐 |

## 3. 앱 파일(AAB) 만드는 법 — 아직 안 함

다다맘은 웹앱(PWA)이라 **TWA(신뢰할 수 있는 웹 활동)** 로 감싸 안드로이드 앱 파일을 만든다.
구글 공식 도구 Bubblewrap 을 쓴다.

필요한 것:
1. **빌드 도구 내려받기** — Node 패키지 `@bubblewrap/cli`, JDK 17, Android SDK (합쳐 약 1GB).
2. **패키지 이름** — 한 번 정하면 못 바꾼다. 제안: `kr.dadaran.dadamom`
3. **서명 키** — 업로드 키를 만들어 안전한 곳에 보관. 잃어버리면 Play 지원으로 재설정 절차가 필요.
4. **도메인 연결(assetlinks.json)** — 앱이 주소창 없이 열리려면
   `https://adultryun188-lang.github.io/.well-known/assetlinks.json` 이 있어야 한다.
   지금 앱은 `/dadamom-app/` 하위 경로라 **`adultryun188-lang.github.io` 라는 새 공개 저장소**가 필요하다.
   (없으면 앱 위쪽에 주소창이 보인다. 동작은 한다.)

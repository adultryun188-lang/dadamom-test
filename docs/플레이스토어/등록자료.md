## 3-0. (참고) 처음 계획

다다맘은 웹앱(PWA)이라 **TWA(신뢰할 수 있는 웹 활동)** 로 감싸 안드로이드 앱 파일을 만든다.
구글 공식 도구 Bubblewrap 을 쓴다.

필요한 것:
1. **빌드 도구 내려받기** — Node 패키지 `@bubblewrap/cli`, JDK 17, Android SDK (합쳐 약 1GB).
2. **패키지 이름** — 한 번 정하면 못 바꾼다. 제안: `kr.dadaran.dadamom`
3. **서명 키** — 업로드 키를 만들어 안전한 곳에 보관. 잃어버리면 Play 지원으로 재설정 절차가 필요.
4. **도메인 연결(assetlinks.json)** — 앱이 주소창 없이 열리려면
   `https://adultryun188-lang.github.io/.well-known/assetlinks.json` 이 있어야 한다.
   지금 앱은 `/dadamom-app/` 하위 경로라 **`adultryun188-lang.github.io` 라는 새 공개 저장소**가 필요하다.
   (없으면 앱 위쪽에 주소창이 보인다. 동작은 한다.)

### 심사용 계정 만들기 (사장님이 직접, 운영 앱에서)

1. 운영 앱 https://dadamom.co.kr/index.html 에서 **이메일로 회원가입** (또는 카카오·구글).
   이메일은 실제로 받을 수 있는 주소여야 한다. Gmail 이면 주소 뒤에 `+review` 를 붙이면 (예: `이름+review@gmail.com`) 같은 메일함으로 온다.
2. 비밀번호는 **심사용으로만 쓰는 새 비밀번호**. 다른 곳에 쓰는 비밀번호를 쓰지 않는다.
3. 아이 정보는 예시로 입력 (예: 7개월·경기). 관리자 권한은 주지 않는다.
4. Play Console › 앱 콘텐츠 › **앱 액세스**에 이메일·비밀번호와 안내 한 줄을 적는다:
   "첫 화면에서 이메일·비밀번호로 로그인하세요. 글·사진은 운영자 검수 후 공개됩니다."
5. 심사 기간에는 관리자 화면 검수 대기를 자주 확인한다 (심사원이 글을 쓰면 검수 대기로 들어간다).
6. 심사가 끝나도 계정은 **지우지 않는다** — 업데이트 심사 때 다시 쓴다.

## 1. 무엇이라고 말할까

> **같은 개월 수 엄마·아빠끼리, 작은 자랑과 고민을 나누는 곳**
> (덧붙이는 말: 광고 없음 · 글과 사진은 운영자 확인 뒤 공개 · 기록은 사진 카드로 남김)

- 보고서의 "작은 자랑 → 다른 부모의 반응" 축을 받아들이고, 1판의 "같은 개월 수·광고 없음"을 얹었습니다.
- **말하지 않는 것**: 다른 앱이나 맘카페와 비교하기, "의학적" 표현, 아직 없는 것(가족 공유·아이폰 앱·체험단·휴대폰 푸시·동네 모임).
- 성장 기록과 사진 카드는 **참여한 사람이 다시 오게 하는 장치**입니다. 첫 홍보의 주인공으로 내세우지 않습니다.
- 말투는 앱과 같이 꾸밈없이 담백하게 씁니다.

## 2. 사람이 지나가는 길

```
카톡·QR·콘텐츠의 링크
 → 승인된 실제 글 한 편 (가입 없이 읽힘)
 → 로그인·가입 → 그 글로 다시 돌아옴
 → 댓글 또는 [자랑] 글
 → 다른 부모의 반응 (내 글에 댓글이 달리면 알림 🔔)
 → 다른 날 다시 옴
 → 계속 쓰는 사람에게 홈 화면 설치·성장 기록 안내
```

**모든 링크는 앱 첫 화면이 아니라 특정 글로 겁니다.** 형식: `…/dadamom-app/community.html?from=<경로>#/p/<글 ID>` (`?from=`은 `#` 앞에 둡니다)

### 지킬 것

- **운영자 글은 운영자 글임을 밝힙니다.** 가짜 회원, AI로 지어낸 육아 경험, 테스트 글로 활발해 보이게 꾸미지 않습니다.
- **반응을 셀 때 운영자(와 나중의 제작자) 반응은 뺍니다.**
- **링크를 건 글은 진행 중에 고치지 않습니다.** 공개 글을 수정하면 다시 검수 대기로 돌아가서(0011) 링크가 끊깁니다.
- 매일: 주제 질문 1개 · 검수 3번 · 첫 글을 쓴 사람에게 1시간 안에 운영자 댓글
- 끝나면 지인 가족에게 "좋았던 것 하나, 불편했던 것 하나"를 직접 묻습니다.

**보는 숫자** (관리자 화면 › 가입 경로 표 + [홍보_측정.md](./홍보_측정.md) SQL, 날짜는 10/27~11/9)

- 첫 댓글이나 첫 글을 쓴 사람
- **운영자가 아닌 회원에게 받은 반응**
- **다른 날** 다시 온 사람

| 이렇게 나오면 | 먼저 볼 것 |
|---|---|
| 클릭은 있는데 참여가 없다 | 첫 글이 공감되는지, 가입을 요구하는 시점, 가입 후 원래 글로 돌아오는지(3절 확인 1~2) |
| 가입은 하는데 글·댓글이 없다 | 주제가 부담스러운지, 공개 범위 안내 |
| 글은 있는데 반응이 없다 | 같은 시기 사람이 충분히 모였는지 |
| 운영자가 답할 때만 움직인다 | 이 대상과 주제에 정말 수요가 있는지, 대상을 바꿀지 |
| 참여 뒤 돌아오지 않는다 | 알림·스크랩이 제대로 작동하는지, 돌아올 이야기가 있는지 |

참고 눈금(근거 없는 출발값): **운영자가 아닌 부모끼리 오간 댓글이 10개를 넘고**, 어느 경로든 가입자 **40% 이상이 다른 날 다시 오면** 2단계로 갑니다.

## 6. 2단계 — 넓히기 (1단계가 통과하면, 11월 중순~)

1. **인스타 육아툰·육아 일상 제작자 1명과 7일 공동 진행.** 조회 수보다 댓글에서 실제 육아 대화가 오가는 계정을 고릅니다.
   본인의 실제 이야기로 다다맘에 글을 쓰고, 외부 콘텐츠는 그 승인된 글로 연결합니다.
   광고·협찬 표시, 콘텐츠 활용 범위, 비용은 미리 합의합니다. 링크는 `?from=ig-<제작자>`로 겁니다.
2. **(선택) 메타 광고 소액 시험** — 앱 설치가 아니라 **승인된 실제 글**로 연결합니다. 소재 A "아이의 작은 도전" vs B "부모의 작은 성취".
   글의 실제 작성자가 광고 활용에 동의한 글만 씁니다. **잃어도 괜찮은 최대 금액**을 사장님이 먼저 정합니다.
3. 효과가 있던 오프라인 경로는 남동구 시설 3~5곳으로 늘립니다.
4. **아껴 둔 알릴 거리**: 플레이스토어 출시(D-U-N-S 이후) → 시험에 참가한 가족에게 리뷰 부탁 / 가족 공유 공개("아빠도 같이 기록", 방침 개정 공지 7일 뒤) / 12월 새 챌린지.

| 보조 채널 | 쓰는 법 | 주의 |
|---|---|---|
| 맘카페 | 운영진이 허락한 제휴만 | 몰래 올리는 홍보·위장 후기는 하지 않습니다 |
| 당근 | 실제 동네 나들이 글이 생긴 뒤 | 첫 유입 채널로 쓰지 않습니다 |
| 블로그·검색 | 공개 글이 쌓이면 천천히 늘어나는 경로 | 당장의 회원 모집으로 기대하지 않습니다 |
| 성장 카드 | 참여한 뒤 선택해서 쓰는 기록·공유 수단 | 주력 홍보로 내세우지 않습니다 |

## 7. 지금은 하지 않을 것

- 1단계 결과 전의 **유료 광고**
- **앱 주소 옮기기**: 육아 기록이 브라우저 저장소에 있어서 주소를 옮기면 사라집니다. `dadamom.co.kr`은 넘겨주기(포워딩)만 하고, 그때도 `?from=`과 `#/p/`가 넘어가는지 확인합니다.
- **광고성 문자·푸시**: 수신 동의자에게만 보내고, `(광고)`를 표시하고, 밤 9시~아침 8시는 따로 동의를 받습니다(정보통신망법 제50조)
- 홍보에서 **체험단·이벤트 보상을 약속하기**

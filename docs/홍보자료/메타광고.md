# 메타(인스타·페이스북) 광고 — 첫걸음 챌린지 경품

작성: Claude Code, 2026-10-19. 첫 달 예산 **20만원** (사장님 결정) 중 **12만원**을 씁니다.

> ⚠️ **운영 반영이 먼저입니다.** 광고를 누른 사람이 로그인 없이 챌린지를 보려면 이번 수정(테스트 `ed6705a`)이
> 운영 앱에 올라가 있어야 합니다. 사장님 Run 한 번 뒤에 광고를 켭니다.

## 1. 예산과 기간

| 항목 | 값 |
|---|---|
| 광고비 | 하루 6,000원 × 20일 = 12만원 (10/27 ~ 11/15) |
| 경품 | 2만 원 상당 × 4명 = 8만원 (12/3 추첨) |
| 합계 | 20만원 |

11/3(1주 뒤)에 결과를 보고 두 광고 중 가입이 적은 쪽을 끄고, 남은 돈을 다른 쪽에 몰아줍니다.

## 2. 광고 두 개 (A·B 비교)

| | 광고 A — 경품을 앞세움 | 광고 B — 공감을 앞세움 |
|---|---|---|
| 이미지 (피드) | `광고/meta-a-feed.png` (1080×1350) | `광고/meta-b-feed.png` |
| 이미지 (스토리·릴스) | `광고/meta-a-story.png` (1080×1920) | `광고/meta-b-story.png` |
| 링크 | `https://adultryun188-lang.github.io/dadamom-app/?from=meta-a#challenge` | `…/dadamom-app/?from=meta-b#challenge` |
| 버튼 | 더 알아보기 | 더 알아보기 |

> 링크는 **github 주소 그대로** 씁니다. `dadamom.co.kr`은 넘겨줄 때 `?from=`과 `#challenge`를 떨어뜨려서 측정이 안 됩니다.

**광고 A 문구**
- 기본 문구:
  ```
  첫걸음 사진 한 장으로 참여하는 다다맘 첫걸음 챌린지예요.
  참가자 중 4명을 추첨해 2만 원 상당 육아용품을 드려요.
  10~24개월 아이 · 11/30 마감 · 12/3 발표
  ```
- 제목: `첫걸음 사진 한 장이면 돼요`
- 설명: `가입 없이 먼저 구경할 수 있어요`

**광고 B 문구**
- 기본 문구:
  ```
  같은 개월 수 엄마·아빠들이 아이의 첫걸음을 모아 서로 응원해요.
  참가자 중 4명을 추첨해 2만 원 상당 육아용품을 드려요.
  11/30 마감 · 12/3 발표
  ```
- 제목: `우리 아이 첫걸음, 응원받아요`
- 설명: `글과 사진은 운영자 확인 뒤 공개돼요`

## 3. 누구에게 보여 줄지 (광고 세트 하나)

| 항목 | 값 |
|---|---|
| 캠페인 목표 | 트래픽 (웹사이트로 사람 보내기) |
| 최적화 | 랜딩 페이지 조회 |
| 지역 | 서울·인천·경기 |
| 연령 | 25~44세 |
| 상세 타기팅 | "부모 › 유아(1~2세) 자녀를 둔 부모"가 메뉴에 있으면 선택, 관심사 "육아" |
| 노출 위치 | 자동(Advantage+) — 피드·스토리·릴스 |
| 일일 예산 | 6,000원 |
| 일정 | 10/27 0시 ~ 11/15 24시 |

광고 세트 하나에 광고 A·B를 같이 넣습니다. 예산이 작아서 세트를 나누면 학습이 잘 안 됩니다.

## 4. 설정 순서 (사장님, 처음 한 번 30분)

1. 페이스북 계정으로 **Meta 비즈니스 관리자**(business.facebook.com)에 들어가 비즈니스(다다란)를 만듭니다.
2. 다다맘 **인스타그램 계정**을 연결합니다(없으면 먼저 만듭니다. 광고는 페이스북 페이지만 있어도 됩니다).
3. **광고 계정**을 만들고 결제 카드를 등록합니다. 결제 정보는 사장님만 넣으세요.
4. 광고 관리자 › 만들기 → 위 3절 값으로 캠페인과 광고 세트를 만듭니다.
5. 광고 A·B를 만들고, 이미지(피드·스토리)·문구·링크를 2절 그대로 넣습니다.
6. 게시하면 메타 심사를 거쳐 시작됩니다.

막히는 화면이 있으면 캡처를 보내 주세요. 어디를 누르면 되는지 알려 드리겠습니다.

## 6. 지킬 것

- 경품 조건(인원·금액·마감·발표일)은 광고와 앱에 똑같이 적습니다. 바꾸면 둘 다 바꿉니다.
- 광고 이미지에 실제 아이 사진은 쓰지 않습니다. 쓰려면 보호자 동의를 받습니다.
- "아기 엄마세요?"처럼 보는 사람의 상황을 단정하는 문구는 메타 광고 정책에 걸릴 수 있어 쓰지 않았습니다.
- 경품은 건당 5만원 이하라 제세공과금 처리가 필요 없습니다(세무사 확인 권장).
- 당첨자 연락은 가입 이메일로 하고, 배송에 필요한 주소·연락처는 당첨자에게만 받아 발송 뒤 지웁니다.

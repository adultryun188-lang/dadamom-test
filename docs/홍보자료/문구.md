## 1. 링크 만들기

```
https://dadamom.co.kr/community.html?from=<경로 코드>#/p/<글 ID>
```

| 경로 | 코드 |
|---|---|
| 카톡 지인 | `friend` |
| 남동구 시설 | `nd-<짧은 이름>` (예: `nd-cafe1`). 시설마다 다르게 |
| 인스타 프로필 | `insta` |
| 제작자 (2단계) | `ig-<제작자 이름>` |

- 코드는 **영문·숫자·하이픈 32자 이내**입니다. 한글이나 공백을 넣으면 경로가 남지 않습니다.
- **글 ID** 찾는 법: 웹 커뮤니티에서 그 글을 열면 주소창 끝 `#/p/` 뒤에 있는 글자입니다.
- 링크를 건 글은 진행 중에 **고치지 않습니다.** 고치면 다시 검수 대기로 돌아가서 링크가 끊깁니다.

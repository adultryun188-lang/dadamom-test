### 1-2. 후보별 자세히

**A. 출산 가방 공개**
- 참가 방법: 가방과 안에 넣을 물건을 바닥·침대에 펼쳐 한 장에 찍고, 손글씨 확인 카드(다다맘·날짜·주수)를 사진 안에 놓습니다. 글에 준비물 목록을 적습니다.
- 검수 기준: ①확인 카드가 보이고 날짜가 올린 날 7일 안 ②카드의 주수가 가입 때 넣은 예정일로 계산한 주수와 ±2주 안 ③사진 속 물건과 목록이 맞음 ④이름·주소·병원명이 찍히지 않음. 넷 중 하나라도 어긋나면 반려하고 다시 올리게 합니다.
- 악용 구멍: (가) 임신부가 아닌 사람이 참가 → 단계가 "임신 중"이고 예정일이 오늘 이후인 회원만 보이고, 1위는 원본 파일과 다른 각도 사진 1장을 더 확인합니다. 경품이 작아(커피 1장) 꾸밀 동기도 약합니다. (나) 판매자 홍보 → 상품 링크·가격·판매 문구가 있으면 반려. (다) 단계를 "임신 중"으로 바꿔 끼어드는 육아 회원 → 앱만 막고 서버는 안 막음 [확인] → 2절 고칠 것 4번.
- 개인정보: 산모수첩, 진료 기록, 택배 송장, 조리원 계약서, 이름표 붙은 가방이 찍히기 쉽습니다 → 규칙에 "이름이 적힌 물건은 빼고" 한 번만 적고, 검수에서 반려합니다.
- 마미톡과: 마미톡은 병원에서 보내는 초음파 영상이 중심입니다 [확인: 01]. 출산 준비물 정보는 여러 앱에 있지만 "실물 사진을 펼쳐 놓고 겨루는 대회"는 찾지 못했습니다 [추정: 02 조사 범위].
- 출산 뒤 연결: 출산 가방은 **출산 직전에 만들고, 출산 직후에 결과가 나옵니다.** 출산 뒤 "실제로 쓴 것·안 쓴 것"을 남기면 그 자체가 02의 B 메시지("또래가 실제로 해결한 방법")가 되고, 같은 사람이 육아 대회(볼살·웃음)로 넘어갑니다. 앱의 "출산 준비물 체크리스트" 메뉴와도 이어집니다 [확인: 첫 화면 메뉴].

**B. 만삭·D라인 (기존 `bump` 보강)**
- 지금 기준의 문제: "(옷 위로 찍어도 좋아요)"는 옷 입은 사진과 맨배 사진 두 기준을 허용합니다. 0036에서 볼살의 "발바닥" 기준을 지운 이유("기준이 둘이면 비교가 안 됨")와 같은 문제입니다. 또 확인 카드가 없어 인터넷 만삭 사진을 가려낼 수 없습니다.
- 고친 기준(안): ①**옷을 입은 채 옆에서 찍은** 상반신~배 사진 1장 ②손글씨 확인 카드(다다맘·날짜·주수)를 손에 들거나 옆에 놓기 ③직접 찍은 사진만. 맨살·속옷 사진은 반려합니다(민감 사진 처리 0040은 커뮤니티 글에만 있음 [확인]).
- 악용: 인터넷 사진(카드로 막음), 쿠션 등으로 꾸민 배(1위만 원본·다른 각도 확인), 지인 동원(7일 규칙).
- 출산 뒤 연결: "같은 자리, 아이와 함께" 백일 사진으로 이어지는 짝 대회가 가능합니다(나중 후보).

**C. 태명 이야기 · D. 편지**: 감정적인 끌림은 크지만, **무엇을 기준으로 1위를 정하는지 검수할 수 없어** 사장님 기준(검수 가능)과 맞지 않습니다. 대회가 아니라 커뮤니티 말머리(경품 없음)로 열고, 출산 뒤 "태명 → 이름"을 그 후 이야기로 남기게 하는 쪽이 맞습니다.

**E. 초음파**: 개인정보(민감정보)·검수 불가·마미톡과 정면 겹침 세 가지가 모두 걸려 **하지 않습니다.**

## 2. 추천: "출산 가방 공개" 상세 설계

### 2-1. 왜 이것인가

| 기준 | 출산 가방 공개 |
|---|---|
| 임신 중 부모에게 이득 | 다른 예비 엄마들의 실제 가방을 **회원끼리** 볼 수 있음. 자랑보다 "도움"이 먼저인 대회라 참가 부담이 낮음 [추정] |
| 검수 가능 | 물건·카드·목록은 사진으로 확인됨. 몸 사진이 없음 |
| 원본 확인 | 확인 카드 + 1위 원본 파일·다른 각도 1장 |
| 개인정보 | 사람 얼굴·몸·의료 기록이 필요 없음 |
| 마미톡과 | 겹치지 않음 |
| 출산 뒤 | "실제로 쓴 것" 그 후 이야기 → 육아 대회. **임신부터 육아까지 한 곳에서 이어지는 것**이 다다맘만의 장점이 됨 |
| 경품·협찬 | 출산용품 브랜드(손수건·수유패드·배냇저고리)에 협찬을 제안하기 쉬움 [추정] |

### 2-2. 대회 이름과 규칙 문구 (관리 화면 대회 칸에 그대로 넣을 값)

| 대상 표시 | `임신 중` (`stage = 'pregnant'`) |

| 기준 1 | `가방과 안에 넣을 물건을 바닥이나 침대에 펼쳐 한 장에 담아 주세요` |

| 글 예시 | `예: 34주, 조리원 2주 예정이라 손수건을 넉넉히 챙겼어요` |
| 경품 | `매달 이 대회 점수 1위에게 편의점 금액권을 드려요. 모든 대회를 통틀어 이달의 대상 1명에게 포토북을 드려요.` |

빠져나갈 구멍 문구("부담되면 일부만", "카드는 없어도")는 넣지 않았습니다. 확인 카드는 모든 참가자에게 같은 기준입니다.

### 2-3. 예시 사진에 담을 기준

예시는 기준을 그대로 보여 줘야 합니다(challenge-purpose).

| 담을 것 | 담지 않을 것 |
|---|---|
| 펼친 가방 전체와 물건 10개 안팎이 한 장에, 하나하나 알아볼 수 있게 | 사람 얼굴·몸 |
| 손글씨 확인 카드 (`다다맘 · 12.01 · 34주`) | 산모수첩, 진료 기록, 택배 송장, 이름표 |
| 밝은 바닥·침대, 위에서 내려다본 구도 | 상품 가격표·판매 링크 |
| 화면 위 "예시" 표시 | 특정 브랜드를 앞세운 구도 |

만드는 법: 무료 사진(Pexels) 중 출산 가방을 펼친 사진에 **확인 카드 자리를 그래픽으로 표시**하고 "예시"를 붙입니다(Claude). 가상으로 만든 사람 사진은 쓰지 않습니다 [확인: 01 — 가상인물 표시 개정안].

### 2-4. 검수 순서 (Claude가 하루 2번 검수할 때)

1. 확인 카드가 보이는가, 날짜가 올린 날 7일 안인가
2. 카드의 주수가 예정일로 계산한 주수와 ±2주 안인가 (검수 화면에 예정일·주수가 보이는지 [확인 필요] → 안 보이면 2-7절 3번)
3. 사진 속 물건과 글의 목록이 맞는가
4. 이름·주소·병원명·가격·판매 링크가 없는가
5. 같은 사진이 다른 계정으로 올라온 적 없는가

하나라도 어긋나면 반려하고 이유를 한 줄로 알립니다(다시 올릴 수 있음).

**1위 원본 확인**: 발표 전, 1위에게 ①원본 사진 파일(촬영 일시 정보 포함) ②같은 가방을 다른 각도로 찍은 사진 1장을 이메일로 받습니다. 못 내면 다음 순위로 넘어갑니다. 이 조건은 규칙 화면의 경품 안내에 미리 적습니다.

### 2-5. 점수 방식과 기간

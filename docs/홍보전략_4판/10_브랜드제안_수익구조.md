# 브랜드가 다다맘에 오는 이유 · 체험단 · 경품 협찬 · 돈 버는 구조 (2026-10-30)

## 0. 먼저 냉정하게

지금 운영 회원은 2명이다. 브랜드에 "사람이 많다"는 말은 할 수 없고, 해서도 안 된다(부풀리면 신뢰가 끝난다).
그래서 제안은 **회원 수와 상관없이 브랜드가 확실히 가져가는 것**으로 짠다.

브랜드(특히 스마트스토어 규모 육아 브랜드)가 실제로 돈을 쓰는 곳은 세 가지다.
1. **후기** — 상세페이지·검색에 쓸 진짜 엄마 후기
2. **광고에 쓸 사진·영상 (아이가 제품을 쓰는 장면)** — 지금은 체험단 업체·크리에이터에게 1건 3만~35만 원을 주고 산다 (01 자료수집)
3. **정확한 시기의 엄마에게 보이기** — 이유식은 6개월, 걸음마 신발은 10개월처럼 제품마다 "딱 그때"가 있다

다다맘은 이 셋을 **제품 몇 개 값으로** 줄 수 있다. 이게 제안의 핵심이다.

## 1. 브랜드가 다다맘에 오는 이유 (제안 메일 첫 문단에 쓸 것)

| 브랜드가 얻는 것 | 다다맘이 가능한 이유 |
|---|---|
| **광고에 써도 되는 아이 사진·후기** | 대회 참가 때 이미 "홍보 활용 동의"를 따로 받는 구조가 있음 (쓰는 곳·2년·철회). 브랜드용 동의 항목만 추가하면 됨 |
| **딱 맞는 월령의 엄마** | 대회가 월령으로 나뉘어 있음 — 배밀이 4~10개월, 첫걸음 10~24개월, 만삭(임신 중). 브랜드 제품 시기에 맞는 대회에만 붙일 수 있음 |
| **"진짜 엄마"라는 신뢰** | 만삭은 임산부 배지, 첫걸음은 원본 영상 확인 등 검수 장치가 있어 가짜 후기·대리 후기가 적음 |
| **돈이 거의 안 듦** | 광고비가 아니라 제품 몇 개. 실패해도 손해가 작다 |
| **초기 파트너 조건** | 나중에 유료로 바뀌어도 첫 파트너는 1년간 같은 조건 유지 — 지금 들어올 이유 |

**하지 말 것:** 회원 수·방문자 수 언급, "효과 보장", 좋은 후기만 쓰게 하기 (표시광고법).

## 2. 체험단을 할 때 브랜드의 메리트

| | 체험단 업체 (레뷰 등) | 다다맘 체험단 |
|---|---|---|
| 비용 | 1명 3만~6만 원 + 제품 | **제품만** |
| 뽑는 기준 | 블로그 방문자 수 | **아이 월령 + 대회 참가 이력 + 육아기록 7일 이상 (0048)** → 실제로 쓸 집 |
| 후기가 남는 곳 | 블로그 1곳 | 다다맘 커뮤니티 + (원하면) 블로그·인스타 — 모두 "협찬" 표시 |
| 광고 소재로 쓰기 | 블로거와 따로 협의 | 신청할 때 "브랜드가 광고에 활용" 동의를 받음 (이미 있음) |
| 그 뒤 | 끝 | 7일 뒤 "그 후 이야기"로 **써 보니 어땠는지** 한 번 더 남음 |

약점(솔직하게 말할 것): 처음엔 신청자가 적다. 그래서 첫 체험단은 **5~10개**로 작게 제안한다.

## 3. 경품을 협찬하면 브랜드의 메리트

**원칙:** 1위 상품권(2만·4만 원)은 그대로 두고, **협찬 제품은 위에 얹는다.** 무명 브랜드 제품만으로는 참가할 이유가 약하다 (09).

| 브랜드가 얻는 것 | 어떻게 |
|---|---|
| **대회 이름 옆 노출** | "이번 달 볼살 자랑은 ○○가 함께해요" — 대회 화면·응원 부탁 링크 미리보기·당근 광고 문구에 들어감 |
| **참가자 전원에게 제품 노출** | 경품 칸에 "1위: 상품권 4만 원 + ○○ 제품" |
| **당첨자 사용 후기 + 사진** | 당첨 조건에 "받은 제품 사용 사진 1장 + 한 줄 후기" (협찬 표시, 활용 동의) |
| **참가작 중 마음에 드는 사진 사용권** | 대회 참가 때 받는 홍보 활용 동의 범위 안에서만 — 브랜드 이름을 동의 문구에 넣어야 함 |
| **월령이 맞는 대회만 고름** | 이유식 브랜드 → 6개월 이후 대회, 걸음마 신발 → 첫걸음 |

**필요한 조치 (Claude):** 대회별 "함께하는 브랜드" 칸, 홍보 활용 동의에 브랜드 이름 넣기. 협찬이 실제로 정해지면 만든다.

## 4. 사장님이 돈 버는 구조 (순서대로)

| 단계 | 언제 (회원 수) | 돈이 나오는 곳 | 비고 |
|---|---|---|---|
| **0. 지금** | ~100명 | **사장님 브랜드 순수소** — 다다맘을 순수소의 자체 채널로 | 아래 설명 |
| 1 | 100~1,000명 | **유료 대회 협찬**: 브랜드가 돈을 내고 대회를 연다 ("○○ 이유식 먹방 대회", 1회 30만~100만 원 [추정]) · **유료 체험단** (1명당 수수료) | 무료 협찬 사례 2~3개가 있어야 팔 수 있음 |
| 2 | 1,000명~ | **포토북·성장앨범 판매** (아이 사진이 이미 다다맘에 있음 — 맘스다이어리 모델) · 지역 광고 (소아과·키즈카페·사진관, 인천 지역 엄마 대상) | 경쟁 조사 19~23 |
| 3 | 1만 명~ | 육아템 판매 수수료, 브랜드 데이터 리포트(개인 식별 없이 월령별 관심) | 개인정보 원칙 지킴 |

### 0단계: 순수소 (사장님 이유식 브랜드)
사장님은 이미 이유식(순수소)·키즈 모자를 팔고 있고, 와디즈·쿠팡·인스타 광고에 돈을 쓰고 있다. 다다맘은 그 고객(6~24개월 엄마)이 모이는 곳이다.
- **순수소를 다다맘의 첫 협찬 브랜드로**: "아이 혼자 잡고 먹기 대회" 경품·체험단 → 순수소 실사용 후기·사진을 광고 소재로 (지금 메타 광고비로 사는 것)
- 효과를 실제로 재서 "다다맘 대회 → 브랜드 후기 n개 → 판매" 사례를 만들면, 그 숫자가 **다른 브랜드에 파는 첫 자료**가 된다
- **법적으로 꼭:** 다다맘 운영자와 순수소가 같은 사람이라는 것을 대회·체험단 화면에 표시 (경제적 이해관계 표시). 숨기면 뒷광고가 된다

### 돈이 안 되는 것 (하지 말 것)
- 지금 배너 광고 자리 팔기 — 노출이 없어 살 사람이 없고, 화면만 싸 보인다
- 회원에게 돈 받기 (유료 기능) — 경쟁 앱이 무료라 지금은 이탈만 생김

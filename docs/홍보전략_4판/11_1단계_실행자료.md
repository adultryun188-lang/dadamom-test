## 1. 당근 광고

**설정** (사장님: 당근 비즈프로필 만들기 → 광고 만들기)
- 지역: 인천 남동구 · 연수구 (반경은 당근 기본값)
- 예산: 하루 8,000원 × 15일 = 120,000원
- 광고 2개를 같이 돌리고, 1주 뒤 가입이 적은 쪽을 끔
- 링크: 위 dg-a / dg-b

| | 광고 A | 광고 B |
|---|---|---|
| 이미지 | `소재/danggn-a.png` | `소재/danggn-b.png` |
| 제목 | 볼살 사진 한 장으로 배민 4만 원 | 처음 참가하면 커피 한 잔 드려요 |
| 본문 | 우리 아이 볼살 자랑 대회. 투표를 가장 많이 받은 아이 1명에게 배민 또는 올리브영 상품권 4만 원을 드려요. 매달 열려요. | 우리 아이 자랑 대회에 처음 참가하면 선착순 30명에게 메가커피 1잔. 1위는 배민·올리브영 상품권 2만~4만 원. |

[확인 필요] 당근 광고 제목·본문 글자 수 제한은 광고 만들기 화면에서 확인 → 넘치면 Claude 가 줄임.
당근이 "광고" 표시를 자동으로 붙인다.

## 2. 인스타 (다다맘 계정 피드, 4장 넘기기)

이미지: `소재/insta-1.png` → `insta-4.png` 순서.

**본문**
```
매달 열리는 우리 아이 자랑 대회

사진이나 1분 영상으로 참가하고,
가족·친구 투표를 가장 많이 받은 아이가 1위예요.

[이번 달 경품]
· 포동포동 볼살 자랑 1위: 배민·올리브영 상품권 4만 원
· 첫걸음 · 뒤집기·배밀이 · 만삭·D라인 1위: 2만 원
· 처음 참가 선착순 30명: 메가커피 1잔

[안내]
· 기간: 매달 1일~말일, 발표는 다음 달 첫 주
· 당첨 연락: 가입한 이메일로. 상품권 받을 휴대폰 번호는 보낸 뒤 바로 지워요
· 참가작은 회원끼리만 봐요

참가는 프로필 링크에서

#육아 #아기사진 #돌아기 #육아맘 #인천맘 #임산부 #만삭사진 #볼살
```
- 이미지 속 예시 사진은 Pexels 무료 사진(상업 이용 가능). 1장에 "예시 사진 · Pexels" 표시함.
- 프로필 링크: 위 ig-bio.

## 3. 맘카페 (홍보 게시판에만)

대부분 맘카페는 홍보 글을 정해진 게시판에서만 허용한다. 카페 규칙을 먼저 확인하고, 홍보 게시판이 없으면 올리지 않는다.

**제목**: [홍보] 아이 사진 한 장으로 참가하는 자랑 대회 (1위 배민 4만 원)

**본문**
```
안녕하세요, 다다맘을 만들고 있는 인천 남동구 운영자예요.

우리 아이 자랑 대회를 매달 열고 있어요.
사진이나 1분 영상으로 참가하고, 투표를 가장 많이 받은 아이에게 상품권을 드려요.

· 볼살 자랑 1위: 배민·올리브영 4만 원
· 첫걸음 · 배밀이 · 만삭 1위: 2만 원
· 처음 참가 선착순 30명: 메가커피 1잔

참가작 사진은 회원끼리만 보이고, 1위는 원본 사진을 확인한 뒤 정해요.
궁금한 점은 댓글로 남겨 주세요.

(링크: cafe-카페이름)
```

## 4. 시작 전 체크
